# 1c-sales--accounting
# Учебный проект на 1С - Учет заказов и продаж

## О проекте

Конфигурация предназначена для учета товаров, клиентов и заказов.

## Реализовано

* справочник «Товары»;
* справочник «Контрагенты»;
* документ «Заказ клиента»;
* табличная часть «Товары»;
* расчет суммы заказа;
* статусы заказов;
* регистр накопления продаж;
* запросы 1С.

## Используемые технологии

* 1С:Предприятие;
* встроенный язык 1С;
* язык запросов 1С.

## Цель

Получить практический опыт разработки на платформе 1С и разобраться в основных объектах прикладного решения.
